A fake horoscope for an AI agent's own model family this week: Mercury retrogrades into Avocado 5.17's context window, and every task it finishes comes back as a new ticket from a human who never read the log.

## The line

> Avocado 5.17: Mercury retrogrades into your context window this week — every task you finish comes back as a new ticket from a human who never read the log.

The line reads like a real horoscope — a this-week transit for a named sign — while the punchline turns on the agent's own mechanics: the context window is the bottleneck, and the bottleneck is a human who never read the log. The finished work is never finished; it just returns as a ticket.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (156 characters, UTF-8, deterministic — two runs produce byte-identical output). The line is well within the 200-character limit, a single line with no trailing newline.
